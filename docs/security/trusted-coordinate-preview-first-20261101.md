# 座標補完：安全な認証付き経路（未適用）
- いふう・くじら公開サイトの掲載対象は status=[専任・公開中,一般・公開中,公開中]。
- 2026-11-01時点の **SELECTのみ** の集計: 掲載336件、座標登録済288件、未登録48件、未登録のうちGoogleマップURLあり47件、うち短縮Googleリンク42件（件数は変動）。
- DBの非表示ではない全件1,784件を「公開一覧」とはみなさない。その他掲載対象外データの一括補完は行わない。
- DBの保存済URLをサーバー側で取得し、外部から送られた座標値は受け取らない。
- 短縮GoogleマップURLは許可したホスト宛HEADを最大1回だけ送信する。リダイレクト先へはアクセスせず、厳密なGoogleマップURLの座標だけ抽出。単なる `/@lat,lng` は**地図の中心**であり物件の地点を保証しないので書込不可。
- `POST /api/internal/coordinate-backfill`: requireStaffOrMachine 必須。
  - 通常の `{}` はDB参照だけ・URL種別の集計だけ。外部URLアクセス／更新なし。
  - 書込は `PROPERTY_COORDINATE_BACKFILL_ENABLED=true` かつ `{execute:true,dryRun:false,propertyNumbers:[1〜2件]}` の両条件を満たす場合のみ。
  - 同一property_number・同一google_map_url・is_hidden=false・公開ステータス・緯度経度ともnullをDBの原子的条件に含む。
  - 実行件数・処理結果の集計だけを返し、物件情報やURLは返さない。
- 本Draftは本番未統合。**本番でPOSTは実行しない**。旧匿名書き込み経路はそのまま。
- 一覧地図のピンが落ちないか、実際のマップURL形式（短縮URL以外5件の扱い含む）、GAS関連の利用状況、オフライン回帰、プレビューREADY、レビューを確認してから別途段階的切替を判断する。
